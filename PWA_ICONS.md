# PWA Icons

For proper PWA installation, you need to add icon files to the `public/` folder:

Required sizes:
- icon-192.png (192x192)
- icon-512.png (512x512)
- favicon.ico (for browser tab)

You can generate these from any image using:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

The app will work as a PWA without icons, but won't show proper app icons during installation.
